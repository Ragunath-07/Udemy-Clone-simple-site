# Udemy Clone Website

A simple Udemy clone website built using HTML and basic CSS. This project is created for learning purposes to practice front-end development fundamentals such as layouts, navigation, and responsive design.

# Features

Home page similar to Udemy’s layout

Course listing section

Navigation bar and footer

Responsive design (basic)

# Technologies Used

HTML5

CSS3

# Project Structure

index.html – Main homepage

style.css – Styles for the website

images/ – Assets used in the website
